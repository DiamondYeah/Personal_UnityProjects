# Project 1 - Go Go Gummi!


## Description

Repo branch containing the Unity project files for the Go Go Gummi project for GAMEDEV.

Scroll below for the images of the project and the video for the explanation of the design.


<br>


Assets include the following for the project:

<ol>
  <b><li>Image for the Ship Inspiration</li></b>
  <b><li>Materials for the ship</li></b>
  <b><li>Prefab for parts of the ship</li></b>
  <b><li>Main Gummi Ship Prefab</li></b>
</ol>


<br>


<b>NOTE:</b>
<i>Does not include a working build. Only the Unity project itself.</i>

### Idea and Design of Gummi Ship

<img width="700" height="500" alt="GummiShip_Design" src="https://github.com/user-attachments/assets/060437b2-32b0-466f-b9f2-d04156669d79" />

Quick sketch I made for my Gummi Ship. It's inspired by the Frost Penguin enemy in Kingdom Hearts as seen in the top right of the image. I pulled inspiration from the enemy by adding the large fan in the back of the ship and the 2 components on the ship's side.

### Built Gummi Ship in Unity

Final design of the Gummi Ship found in Unity. It's meant to be a water and flying ship with the large fan in the back and the 2 smaller fans in the wings acting as propellers. Due to the design of the ship it's meant to be parked in water rather thnn land.
