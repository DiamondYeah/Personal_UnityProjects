# Project 3 - Laser Room!


## Description

Repo branch containing the Unity project files for the Laser Room Game for GAMEDEV.

Scroll below for the images of the project and the video for the explanation of the game and its mechanics.


<br>


Assets include the following for the project:

<ul>
  <b><li>Player Movement and Jump</li></b>
  <b><li>Smooth 3rd Person Follow</li></b>
  <b><li>Buttons that rotate and move platforms</li></b>
  <b><li>3 levels!!</li></b>
  <b><li>Button to reset controlled platforms in level</li></b>
  <b><li>Checkpoints</li></b>
</ul>


<br>


### IMPORTANT NOTE:
<b><i>Does not include a working build. Only the Unity project itself.</i><b>

<b>If materials don't render from the Library folder, delete the Library folder in File Explorer and reopen the Project again in Unity. It should recreate the Library folder again and allow proper rendering of materials.</b>
