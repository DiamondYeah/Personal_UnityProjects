# Project 6 - Super Sentai Transform!

## Description

Repo branch containing the Unity project files for the Super Sentai Transform Project for GAMEDEV.

Scroll below for the images of the project and the video for the explanation of the particles and implementation.


<br>


Assets include the following for the project:
<ul>
  <b><li>2 VFXs: Auramaxxing & Lightning Ball inspired by ATLA</li></b>
  <b><li>Implementations made via Unity Particle System</li></b>
  <b><li>Scene demonstrates implementation of said 2 particles</li></b>
</ul>


<br>

### IMPORTANT NOTE:
<b><i>Does not include a working build. Only the Unity project itself.</i><b>

<b>If materials don't render from the Library folder, delete the Library folder in File Explorer and reopen the Project again in Unity. It should recreate the Library folder again and allow proper rendering of materials.</b>
